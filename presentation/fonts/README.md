# Deck fonts

The deck uses three free fonts (SIL Open Font License): **Fraunces** (headlines), **DM Sans** (text) and **Geist Mono**
(numbers and labels). Install the six `.ttf` files here before opening `StuntDouble.pptx` in PowerPoint or Keynote
(double-click each file → Install), or the app substitutes other fonts. Google Slides has all three built in.

`StuntDouble.pdf` has them embedded and looks right everywhere.
